# FoodDash

Production-oriented food delivery platform with FastAPI, PostgreSQL, JWT authentication, Redis/RQ jobs, PayFast, Google Maps, restaurant/driver/admin portals, WebSockets, and Docker deployment.

## Run

Copy `.env.example` to `.env`, set credentials, then run `docker compose up --build`.

See `DEPLOYMENT.md` for deployment and `docs/REAL_API_MIGRATION.md` for provider setup.
